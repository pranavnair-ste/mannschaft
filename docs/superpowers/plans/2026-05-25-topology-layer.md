# Topology Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build 5 named execution topologies (Sequential, Parallel, Synthesis, Nested, Persistent) plus a Coordinator that wire ClawTeam's leader/worker + task DAG primitives into user-selectable run shapes for the Pi-Agent Harness.

**Architecture:** Each topology is a thin coordinator that emits a `team.toml` (ClawTeam team template) plus a list of `TaskDef` objects with the correct `--blocked-by` dependency graph. The `Coordinator` selects a topology by `RunSpec.mode`, primes corpus via Plan 3, launches the team via Plan 1's `ClawTeamClient`, and schedules a post-completion improve run via Plan 4 when `wait_for_completion` resolves.

**Tech Stack:** Python 3.10+, `dataclasses` + `enum`, `tomli_w` for `team.toml` emission (TOML library, not string templates — see Decisions §1), `pytest` for tests, `unittest.mock` for ClawTeam client + Plan 4 runner mocks.

## Decisions Locked

1. **`team.toml` generation** — Use `tomli_w.dumps` (Python stdlib `tomllib` is read-only). Each topology builds a `dict` matching ClawTeam's team template schema, then writes via `tomli_w` to a temp file passed to `ClawTeamClient.launch_team`. **Rationale:** ClawTeam's TOML schema includes nested tables (`[agents.alice]`) and arrays of inline tables (tools, blocked_by) — string templating is brittle for nested structures with optional fields. `tomli_w` is a 3-line addition to `pyproject.toml` and gives quoting/escaping correctness for free.
2. **`RunHandle` linking** — `RunHandle.team_name` is the ClawTeam team identifier (used in worktree paths like `clawteam/{team_name}/{agent}`). `RunHandle.run_id` is a UUID4 generated by the Coordinator at launch time and threaded through trajectory capture and improve scheduling.
3. **Completion detection** — Rely on `ClawTeamClient.wait_for_completion` (Plan 1 contract). Topology layer does not poll directly; the Coordinator awaits Plan 1's blocking call. Nested topology recurses through its own `Coordinator.launch` for child teams.
4. **Nested depth limit** — `NestedTopology(max_depth=2)` by default; tracked via a `depth` kwarg on `plan()` that increments before child recursion and rejects with `RecursionError` when exceeded.
5. **`sync_mode`** — `sync_all` rewrites every `[agents.<name>].profile` field in `team.toml` to a single profile string (resolved from `Config.default_sync_profile`). `per_agent` reads each `AgentSpec.model_tier` and maps via `Config.profile_for_tier(tier)`.
6. **Session-id semantics (Persistent)** — `RunSpec.session_id` (optional field added in this plan) is the persistence key. `PersistentTopology` requires it; absent, raises `ValueError`. Corpus prime call passes `session_id` to `corpus.reader.prime` so Plan 3 filters by tag.

    ```python
    """Topology layer base types and abstract class.

    Provides the shared vocabulary used by all five named topologies and the
    Coordinator. Downstream plans (6/7/8) import from here.
    """
    from __future__ import annotations

    from abc import ABC, abstractmethod
    from dataclasses import dataclass, field
    from datetime import datetime
    from enum import Enum
    from typing import TYPE_CHECKING

    if TYPE_CHECKING:
        from pi_harness.improve.runner import ImproveResult


    class TopologyMode(str, Enum):
        SEQUENTIAL = "sequential"
        PARALLEL = "parallel"
        SYNTHESIS = "synthesis"
        NESTED = "nested"
        PERSISTENT = "persistent"


    class Role(str, Enum):
        ORCHESTRATOR = "orchestrator"
        BUILDER = "builder"
        SCOUT = "scout"
        REVIEWER = "reviewer"
        SYNTHESIZER = "synthesizer"


    class ModelTier(str, Enum):
        REASONING = "reasoning"
        FAST = "fast"


    class SyncMode(str, Enum):
        SYNC_ALL = "sync_all"
        PER_AGENT = "per_agent"


    @dataclass
    class AgentSpec:
        """One agent's declaration inside a RunSpec."""
        name: str
        role: Role
        model_tier: ModelTier
        tools: list[str] = field(default_factory=list)
        expertise_classifications: list[str] = field(default_factory=list)


    @dataclass
    class RunSpec:
        """User-facing run declaration. Consumed by Coordinator.launch."""
        goal: str
        agents: list[AgentSpec]
        mode: TopologyMode
        sync_mode: SyncMode
        corpus_classifications: list[str]
        session_id: str | None = None  # required for PERSISTENT mode


    @dataclass
    class RunHandle:
        """Returned by Coordinator.launch. Threaded into trajectory capture +
        post-completion improve scheduling."""
        run_id: str
        team_name: str
        started_at: datetime
        topology: TopologyMode


    @dataclass
    class TaskDef:
        """One node in a ClawTeam task DAG. blocked_by lists task_ids that must
        complete before this task is unblocked."""
        task_id: str
        agent_name: str
        goal: str
        blocked_by: list[str] = field(default_factory=list)


    @dataclass
    class RunResult:
        """Returned by Topology.wait_for_completion. Mirrors Plan 1's
        ClawTeamClient.wait_for_completion return."""
        run_handle: RunHandle
        success: bool
        terminal_states: dict[str, str]  # task_id -> "done" | "failed" | "cancelled"


    class Topology(ABC):
        """Abstract base. Every named topology subclasses this."""

        @abstractmethod
        def plan(self, spec: RunSpec, depth: int = 0) -> list[TaskDef]:
            """Build the task DAG. Returns a flat list of TaskDef whose blocked_by
            references form the dependency graph. depth is used by NestedTopology
            for recursion-limit checks."""
            ...

        def build_team_toml_dict(self, spec: RunSpec, tasks: list[TaskDef]) -> dict:
            """Build the dict form of team.toml. Subclasses may override for
            topology-specific tweaks (e.g. Nested adds a child-team section).
            """
            from pi_harness.config import Config  # local import; avoids cycle
            cfg = Config.load()
            return {
                "team": {
                    "name": self._team_name(spec),
                    "goal": spec.goal,
                },
                "agents": {
                    a.name: {
                        "role": a.role.value,
                        "profile": (
                            cfg.default_sync_profile
                            if spec.sync_mode == SyncMode.SYNC_ALL
                            else cfg.profile_for_tier(a.model_tier.value)
                        ),
                        "tools": a.tools,
                    }
                    for a in spec.agents
                },
                "tasks": [
                    {
                        "id": t.task_id,
                        "agent": t.agent_name,
                        "goal": t.goal,
                        "blocked_by": t.blocked_by,
                    }
                    for t in tasks
                ],
            }

        def _team_name(self, spec: RunSpec) -> str:
            """Deterministic team-name slug. Coordinator overrides with run_id."""
            return f"{spec.mode.value}-team"
    ```

    ```python
    """Sequential topology: A -> B -> C -> ... -> N."""
    from __future__ import annotations

    from pi_harness.topology.base import RunSpec, TaskDef, Topology


    class SequentialTopology(Topology):
        """Linear chain. Each agent blocked by the previous one."""

        def plan(self, spec: RunSpec, depth: int = 0) -> list[TaskDef]:
            if not spec.agents:
                raise ValueError("SequentialTopology requires at least one agent")
            tasks: list[TaskDef] = []
            for i, agent in enumerate(spec.agents):
                task_id = f"seq-{i:03d}-{agent.name}"
                blocked = [tasks[i - 1].task_id] if i > 0 else []
                tasks.append(TaskDef(
                    task_id=task_id,
                    agent_name=agent.name,
                    goal=spec.goal,
                    blocked_by=blocked,
                ))
            return tasks
    ```

    ```python
    """Parallel topology: leader -> [workers] -> merge."""
    from __future__ import annotations

    from pi_harness.topology.base import RunSpec, TaskDef, Topology


    class ParallelTopology(Topology):
        """Convention: first agent = leader, last agent = merger, middle = workers."""

        MIN_AGENTS = 3  # leader + at least 1 worker + merger

        def plan(self, spec: RunSpec, depth: int = 0) -> list[TaskDef]:
            if len(spec.agents) < self.MIN_AGENTS:
                raise ValueError(
                    f"ParallelTopology requires at least {self.MIN_AGENTS} agents "
                    f"(leader + worker(s) + merger); got {len(spec.agents)}"
                )
            leader = spec.agents[0]
            merger = spec.agents[-1]
            workers = spec.agents[1:-1]

            leader_task = TaskDef(
                task_id=f"par-leader-{leader.name}",
                agent_name=leader.name,
                goal=spec.goal,
                blocked_by=[],
            )
            worker_tasks = [
                TaskDef(
                    task_id=f"par-worker-{i:03d}-{w.name}",
                    agent_name=w.name,
                    goal=spec.goal,
                    blocked_by=[leader_task.task_id],
                )
                for i, w in enumerate(workers)
            ]
            merge_task = TaskDef(
                task_id=f"par-merge-{merger.name}",
                agent_name=merger.name,
                goal=spec.goal,
                blocked_by=[wt.task_id for wt in worker_tasks],
            )
            return [leader_task, *worker_tasks, merge_task]
    ```

    ```python
    """Synthesis topology: Parallel + synthesizer-role merger that votes/synthesizes."""
    from __future__ import annotations

    from pi_harness.topology.base import Role, RunSpec, TaskDef
    from pi_harness.topology.parallel import ParallelTopology


    class SynthesisTopology(ParallelTopology):
        """Same fan-out shape as Parallel, but enforces SYNTHESIZER role at merge
        and rewrites the merge task goal to a synthesis directive."""

        def plan(self, spec: RunSpec, depth: int = 0) -> list[TaskDef]:
            if not spec.agents or spec.agents[-1].role != Role.SYNTHESIZER:
                raise ValueError(
                    "SynthesisTopology requires the final agent to have synthesizer role"
                )
            tasks = super().plan(spec, depth=depth)
            merge = tasks[-1]
            merge.goal = (
                f"Synthesize and vote across worker outputs to produce a single "
                f"answer for: {spec.goal}"
            )
            return tasks
    ```

    ```python
    """Nested topology: coordinator spawns a recursive child team."""
    from __future__ import annotations

    from pi_harness.topology.base import RunSpec, TaskDef, Topology


    class NestedTopology(Topology):
        """First agent is the coordinator; all others are subagents inside a child
        team. The coordinator unblocks the child-team launch; subagent tasks
        within the child are blocked by the coordinator's completion (modeled as
        --blocked-by here for the DAG; ClawTeam handles the actual sub-team
        spawn from the coordinator's tmux session)."""

        def __init__(self, max_depth: int = 2) -> None:
            self.max_depth = max_depth

        def plan(self, spec: RunSpec, depth: int = 0) -> list[TaskDef]:
            if depth > self.max_depth:
                raise RecursionError(
                    f"NestedTopology exceeded max depth {self.max_depth} (current={depth})"
                )
            if not spec.agents:
                raise ValueError("NestedTopology requires at least one coordinator agent")

            coord_agent = spec.agents[0]
            sub_agents = spec.agents[1:]

            coord_task = TaskDef(
                task_id=f"nest-coord-{coord_agent.name}",
                agent_name=coord_agent.name,
                goal=spec.goal,
                blocked_by=[],
            )
            sub_tasks = [
                TaskDef(
                    task_id=f"nest-sub-{i:03d}-{a.name}",
                    agent_name=a.name,
                    goal=spec.goal,
                    blocked_by=[coord_task.task_id],
                )
                for i, a in enumerate(sub_agents)
            ]
            return [coord_task, *sub_tasks]

        def build_team_toml_dict(self, spec: RunSpec, tasks: list[TaskDef]) -> dict:
            dct = super().build_team_toml_dict(spec, tasks)
            parent_name = dct["team"]["name"]
            dct["team"]["child"] = {
                "parent_team": parent_name,
                "name": f"child_of_{parent_name}",
            }
            return dct
    ```

    ```python
    """Persistent topology: session_id tags trajectory + corpus subset for reuse."""
    from __future__ import annotations

    from pi_harness.topology.base import RunSpec, TaskDef
    from pi_harness.topology.sequential import SequentialTopology


    class PersistentTopology(SequentialTopology):
        """Sequential shape, but binds the run to a session_id used by Plan 3's
        corpus reader to filter prime entries and by Plan 4's improve runner to
        append back into the same session subset.

        This IS pillar 1's storage mechanism — runs in the same session compound."""

        def plan(self, spec: RunSpec, depth: int = 0) -> list[TaskDef]:
            if not spec.session_id:
                raise ValueError(
                    "PersistentTopology requires RunSpec.session_id to bind the "
                    "run to a session for corpus + trajectory reuse"
                )
            return super().plan(spec, depth=depth)

        def build_team_toml_dict(self, spec: RunSpec, tasks: list[TaskDef]) -> dict:
            dct = super().build_team_toml_dict(spec, tasks)
            dct["team"]["session_id"] = spec.session_id
            return dct

        def prime_corpus(self, spec: RunSpec, reader) -> list:
            """Wrapper around Plan 3's reader.prime that forces session_id filter."""
            return reader.prime(
                classifications=spec.corpus_classifications,
                session_id=spec.session_id,
            )
    ```

    ```python
    """Coordinator: dispatch + lifecycle wrapper around topologies.

    Selects the right Topology subclass by RunSpec.mode, primes corpus,
    emits team.toml, launches via ClawTeamClient, and schedules post-completion
    improve.
    """
    from __future__ import annotations

    import tempfile
    import uuid
    from datetime import datetime, timezone
    from pathlib import Path

    import tomli_w

    from pi_harness.topology.base import (
        RunHandle,
        RunResult,
        RunSpec,
        SyncMode,
        Topology,
        TopologyMode,
    )
    from pi_harness.topology.nested import NestedTopology
    from pi_harness.topology.parallel import ParallelTopology
    from pi_harness.topology.persistent import PersistentTopology
    from pi_harness.topology.sequential import SequentialTopology
    from pi_harness.topology.synthesis import SynthesisTopology

    _TOPOLOGY_REGISTRY: dict[TopologyMode, type[Topology]] = {
        TopologyMode.SEQUENTIAL: SequentialTopology,
        TopologyMode.PARALLEL: ParallelTopology,
        TopologyMode.SYNTHESIS: SynthesisTopology,
        TopologyMode.NESTED: NestedTopology,
        TopologyMode.PERSISTENT: PersistentTopology,
    }


    class Coordinator:
        """Single entry-point for launching runs across all five topologies."""

        def __init__(
            self,
            config,
            clawteam_client,
            corpus_reader,
            improve_runner,
        ) -> None:
            self._config = config
            self._clawteam_client = clawteam_client
            self._corpus_reader = corpus_reader
            self._improve_runner = improve_runner
            self._last_result: dict[str, RunResult] = {}  # run_id -> result

        def launch(self, spec: RunSpec) -> RunHandle:
            topology_cls = _TOPOLOGY_REGISTRY.get(spec.mode)
            if topology_cls is None:
                raise ValueError(f"Unknown topology mode: {spec.mode}")
            topology = topology_cls()

            # 1. Pre-launch corpus prime (Plan 3).
            self._corpus_reader.prime(
                classifications=spec.corpus_classifications,
                session_id=spec.session_id,
            )

            # 2. Build task DAG.
            tasks = topology.plan(spec)

            # 3. Build team.toml dict + apply sync_mode.
            team_toml_dict = topology.build_team_toml_dict(spec, tasks)
            self._apply_sync_mode(team_toml_dict, spec)

            # 4. Emit run_id and team_name; thread into the dict.
            run_id = f"run-{uuid.uuid4()}"
            team_toml_dict["team"]["name"] = f"team-{run_id}"
            team_toml_dict["team"]["run_id"] = run_id

            # 5. Write team.toml to a temp file.
            tmp_dir = Path(tempfile.gettempdir())
            team_toml_path = tmp_dir / f"team-{run_id}.toml"
            team_toml_path.write_text(tomli_w.dumps(team_toml_dict))

            # 6. Launch via Plan 1.
            self._clawteam_client.launch_team(
                team_toml=team_toml_dict,
                team_toml_path=str(team_toml_path),
                run_id=run_id,
            )

            return RunHandle(
                run_id=run_id,
                team_name=team_toml_dict["team"]["name"],
                started_at=datetime.now(timezone.utc),
                topology=spec.mode,
            )

        def wait_for_completion(self, handle: RunHandle, timeout: float) -> RunResult:
            result = self._clawteam_client.wait_for_completion(handle, timeout=timeout)
            self._last_result[handle.run_id] = result
            return result

        def on_completion(self, handle: RunHandle) -> None:
            """Called after wait_for_completion. Triggers Plan 4's improve run
            iff the run succeeded."""
            result = self._last_result.get(handle.run_id)
            if result is not None and getattr(result, "success", False):
                self._improve_runner.run_for_completed_run(handle)

        def _apply_sync_mode(self, team_toml_dict: dict, spec: RunSpec) -> None:
            if spec.sync_mode == SyncMode.SYNC_ALL:
                for agent_cfg in team_toml_dict.get("agents", {}).values():
                    agent_cfg["profile"] = self._config.default_sync_profile
            # PER_AGENT path: profiles already set by Topology.build_team_toml_dict
            # using config.profile_for_tier.
    ```
